# 项目毕业计划

"毕业"指三个目标都交付、任何人克隆仓库后照着 README 能用起来、之后不再需要为它返工。

这份计划在 2026-11-22 傍晚重写过一次:三个目标的功能都已经做完并推送(`main` 在 `ee0385c`),
剩下的是验收、收尾和毕业之后可选的方向。已经完成的阶段的细节见 [roadmap.md](roadmap.md)。

## 7. 毕业之后可选

这些都不是毕业条件。按"投入小、看得见"排在前面。

| 方向 | 内容 | 投入 | 说明 |
|---|---|---|---|
| 危险牌提示(G3b.7) | 提示哪些牌打出去容易点炮 | 1–2 天 | 用规则算:各家缺哪门、已经见过的牌、谁副露多、谁可能听牌。不能用现在的模型来给,它自己的点炮率有 50% |
| 段位梯补中间档 | 自我对弈现在只有"初期"和"最好的一版"两档 | 12 小时机器时间 | 带着里程碑存档重跑一次长跑(`--keep-every` 已经加了),段位梯就能有 100 万、300 万、600 万局的版本 |
| 让模型学会防守 | 把点炮率从 50% 降下来 | 2–3 天,加 12 小时以上机器时间,结果不保证 | 可以试的:状态里加"这张牌有多危险"的特征;对手池里放更会听牌的对手;点炮单独加一点惩罚。这是研究性质的工作,可能试了没有效果 |
| 在线试玩 | 部署到云服务器,给一个链接就能玩 | 1–2 天,另需服务器 | 现在的服务端同一时间只有一场牌局,要先改成每个访问者各一场。可以等你的腾讯云服务器准备好一起做 |
| 放进个人网站 | 项目页:一段观战的录屏、段位梯的表、仓库链接 | 半天 | 不需要部署服务,录屏就够 |
| 每日一题 | "这手牌打哪张",答完显示模型的选择和概率 | 1 天 | 题目可以从牌谱里自动挑模型很有把握的局面 |
| 战绩面板 | 多局后的胡牌率、点炮率、和模型一致率的变化 | 半天到 1 天 | 数据都在 `records/` 里 |
