# 项目毕业计划

"毕业"指三个目标都交付、任何人克隆仓库后照着 README 能用起来、之后不再需要为它返工。
这里列的是从现在(2026-11-22)到毕业还要做的全部事情。已经完成的阶段见 [roadmap.md](roadmap.md)。

## 毕业标准

| 目标 | 毕业时要满足 | 现状 |
|---|---|---|
| 1. 可使用的麻将软件 | 浏览器里 1 人对 3 个电脑打完整局;所有按钮都由人实际点过 | 已可用;"胡""杠"按钮和手机布局还没人工验证 |
| 2. 训练 AI | 训练模型对 3 个规则型 AI,至少 1 万局同牌对比,95% 置信区间下界大于 0 | 模仿模型已持平;自我对弈训练中,15 万局时 +0.100(区间 +0.005 到 +0.194,4000 局) |
| 3. AI 加入对局 | 界面上能选训练模型当对手;出一手牌不超过 1 秒;有测试证明它拿不到别人的牌 | 已做完(G3);入座的暂时是模仿模型,等 G1 出了过关的模型再替换 |
| 可复现 | 新机器克隆仓库,照 README 能装、能玩、能重新训练 | 代码都在仓库里;模型文件放在 `models/`,随仓库走 |

## G1 自我对弈长跑

| 编号 | 任务 | 做完的标准 | 状态 |
|---|---|---|---|
| G1.1 | 试跑 12 分钟 | 流程通,成绩不掉 | ✅ 14.2 万局时 +0.100 |
| G1.2 | 续跑 60 分钟 | 曲线继续上升或至少不退 | 跑到第 30 轮(26.6 万局)时并入长跑,见下面的说明 |
| G1.3 | 长跑 12 小时(约 1000 万局) | 定期评估的成绩稳定为正 | 进行中,2026-11-22 03:06 从第 30 轮开始 |
| G1.4 | 看曲线,决定收工、续跑还是调参数 | 见下表 | 等 G1.3 |
| G1.5 | 过关确认:`best.pt` 用没用过的种子打 2500 副牌 × 4 | 区间下界大于 0 | 等 G1.4 |

| G1.4 的几种情况 | 做法 |
|---|---|
| 成绩稳定在 +0.2 以上,下界大于 0 | 收工,进 G1.5 |
| 还在涨但没到 | `--resume` 再跑一段 |
| 涨到一个水平就停了 | 加大熵系数或调学习率再跑;对手池里提高旧版本的比例 |
| 成绩掉回去甚至为负 | 回到 `best.pt`,调小学习率 |
| 怎么调都不显著为正 | 用模仿模型毕业:目标 2 改写成"与规则型 AI 持平的神经网络",如实写进文档 |

一次事故(2026-11-22):排队的长跑没有等 G1.2 结束就启动了,02:46 到 03:04 之间两个训练同时在跑,互相抢显卡,每轮从 40 秒变成 3 分钟。发现后两个都停掉,删掉日志里重复的行,从存档(第 30 轮)只启动一个长跑。模型本身没有损坏,只是这 18 分钟的训练效率很低,日志里这几轮的用时偏大。

已知的问题:点炮率 44%,和规则型 AI 一样不会防守。这是模型最大的提升空间,也是判断训练有没有学到新东西的主要指标。

## G3 AI 入座

| 编号 | 任务 | 位置 | 做完的标准 |
|---|---|---|---|
| G3.1 | 导出 ONNX,用 onnxruntime 在 CPU 上推理 | `ai/export.py`、`ai/onnx_agent.py` | 和 PyTorch 版的输出一致;对局软件不需要装 PyTorch |
| G3.2 | 模型文件的发布方式 | 见下面的决定 | 克隆仓库后不用自己训练就能选到训练模型 |
| G3.3 | 难度档:简单、普通(规则型)、困难(训练模型) | `ai/__init__.py`、开始页 | 开始页多一档;没有模型文件时这一档变灰并说明原因 |
| G3.4 | 延迟 | `tests/` | 出一手牌不超过 1 秒(现在 PyTorch 单线程是 1.4 毫秒) |
| G3.5 | 公平性测试 | `tests/test_server.py` | 断言交给 AI 的数据里没有别人的手牌和牌墙 |
| G3.6 | 提示模式:轮到你时显示 AI 建议打哪张 | 服务端接口 + 牌桌界面 | 可开关;默认关 |
| G3.7 | 复盘分析:回放时标出 AI 认为更好的选择 | 牌谱接口 + 回放界面 | 每一步显示 AI 的首选和你的选择是否一致 |

**状态(2026-11-22):G3.1–G3.7 全部做完**,包括提示模式和复盘分析。模型文件放进了仓库(`models/chuanma.onnx`,6 MB)。现在入座的是模仿模型;G1 出了过关的模型后,用 `python -m ai.export` 重新导出替换即可,代码不用改。
