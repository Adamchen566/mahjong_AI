# 阶段 4 任务清单

阶段 4 的目标:训练出的模型在至少 1 万局同牌对比中,对规则型 AI 的平均得分显著为正。
方案的道理写在 [ai-training.md](ai-training.md),这里只列要做的事、做完的标准和先后顺序。

写于 2026-11-22。标"实测"的数字是当天在开发机上跑出来的,标"估计"的还没有验证。

## 总览

| 步骤 | 内容 | 要显卡 | 状态 | 预计用时 |
|---|---|---|---|---|
| 准备 | CUDA 版 PyTorch、训练依赖 | — | ✅ 完成 | — |
| 4a | 规则型 AI | 否 | ✅ 完成 | — |
| 4b | 训练环境:编码、掩码、并行对局、数据生成工具 | 否 | ✅ 完成 | — |
| 4c | 模仿学习:网络学规则型 AI | 是 | ✅ 完成,实力与规则型 AI 持平 | — |
| 4d | 自我对弈:PPO | 是 | ✅ 完成 | 12 小时跑了 897 万局(每轮约 8500 局、42 秒,其中更新占 28 秒);成绩见 [graduation-plan.md](graduation-plan.md) |
| 4e | 评估与发布门槛 | 否 | 基础版已有,其余未开始 | 穿插在 4c、4d 里做 |

实测速度(Ryzen 7 9800X3D,12 进程):

| 项 | 结果 | 说明 |
|---|---|---|
| 编码一个局面 | 16.8 微秒 | 经视图字典是 22.3 微秒;价值头的额外输入 9.9 微秒 |
| 单进程,随机策略 | 2.9 万个决定/秒 | 对局 + 编码 + 记轨迹 |
| 12 进程,随机策略 | 12.5 万个决定/秒,每秒 162 批(每批 768 个局面) | **不含网络推理**,是自我对弈速度的上限 |
| 12 进程,1 个随机 + 3 个规则型 AI | 2200 个决定/秒,93 局/秒 | 规则型 AI 每步要算向听数,是瓶颈 |
| 4 个规则型 AI 互打并存盘 | 130–336 局/秒 | 2400 局的短跑是 130;6 万局的长跑是 336(向听数的缓存热了之后更快)。每局 49 个有选择的决策点;存盘后每局 3.7 KB |

从这些数字得出的两个结论,已经写进 4c、4d 的任务里:

| 结论 | 依据 | 影响 |
|---|---|---|
| 模仿数据很便宜 | 8.5 万局实际用了 5 分钟、320 MB | 数据量可以放开给,不用省 |
| 规则型 AI 不能当自我对弈的日常陪练 | 有它在的局只有 93 局/秒,纯网络对局的上限是它的十几倍 | 4d 的对手池里用"模仿模型"顶替它;规则型 AI 本尊只在评估时出场 |

顺带修了一个问题:规则型 AI 在换三张途中如果前面的牌不是自己选的,会报错(生成带随机探索的数据时才会碰到)。

## 4c 模仿学习 ✅

目标:网络和规则型 AI 同牌对比,平均得分差在误差范围内。**已达到**,C1–C10 全部完成。

| 结果(2026-11-22) | 数值 |
|---|---|
| 训练数据 | 6 万局照常打 + 2 万局带 10% 随机探索,共 4,035,752 个决策点;验证集 5 千局,245,735 个 |
| 网络 | 10 个残差块 × 128 通道,1,777,365 个参数 |
| 训练 | 4 轮,15,764 步,548 秒;每秒 2.9 万个样本;训练时显存总共用了 3.2 GB(其中约 1.4 GB 是桌面本身占的) |
| 验证集上和规则型 AI 选同一步的比例 | 97.9%(出牌 97.1%,换三张 97.8%,定缺 99.6%,碰 99.9%,胡 100%) |
| **模仿模型 对 3 个规则型 AI**(1 万局同牌对比) | 平均每局 -0.006 分,95% 置信区间 -0.054 到 +0.042 → **持平,过关** |
| 模仿模型 对 3 个简单策略(2400 局) | +0.651 分,区间 +0.396 到 +0.905(规则型 AI 自己是 +0.715) |
| 模型文件 | `checkpoints/bc/best.pt`(不入库) |

| 重现的命令 | |
|---|---|
| 生成数据 | `python -m ai.generate --games 60000 --workers 12 --seed 0 --out data/bc_rule/clean` |
| | `python -m ai.generate --games 20000 --workers 12 --seed 1000000 --explore 0.1 --out data/bc_rule/explore` |
| | `python -m ai.generate --games 5000 --workers 12 --seed 2000000 --out data/bc_rule_val` |
| 训练 | `python -m ai.train_bc --data data/bc_rule/clean data/bc_rule/explore --val data/bc_rule_val --out checkpoints/bc --epochs 4` |
| 评估 | `python -m ai.evaluate --candidate checkpoints/bc/best.pt --baseline rule -n 2500 --workers 12` |

训练中看到的一件事:看全场的价值头在验证集上的误差(0.170)并不比普通价值头(0.165)低,而且后两轮在变差。也就是说它在模仿数据上没有学到额外的东西。4d 里要重新确认它是否有用(任务 D4)。
