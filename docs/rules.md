# 规则说明

这份文档写的是 **引擎实际实现的规则**。四川麻将各地打法不同,有分歧的地方都做成了配置项(`chuanma/config.py` 的 `RuleConfig`),下面每处都标了默认值。

## 1. 牌与座位

| 项 | 规定 |
|---|---|
| 牌 | 万、筒、条各 1–9,每种 4 张,共 108 张;没有字牌和花牌 |
| 座位 | 0 东、1 南、2 西、3 北 |
| 行牌顺序 | 0 → 1 → 2 → 3 → 0;"下家"指座位号加 1 |
| 庄家 | 开局时由调用方指定(`Game(dealer=...)`),引擎不管多局之间的轮庄 |

## 2. 一局的流程

| 步骤 | 规定 |
|---|---|
| 发牌 | 每人 13 张,庄家 14 张 |
| 换三张 | 每人选 **同一花色** 的 3 张牌换出。方向随机:给下家、对家或上家。配置 `exchange_three`,默认开 |
| 定缺 | 每人选一门花色作为缺门。全部选完后同时公开 |
| 行牌 | 庄家先出牌,之后轮流摸牌、出牌 |
| 结束 | 三家胡牌,或者牌墙摸完(流局) |

## 3. 行牌规则

| 规则 | 规定 |
|---|---|
| 缺门 | 手里还有缺门牌时只能打缺门牌,不能胡;缺门的牌不能碰、不能杠 |
| 吃 | 没有吃 |
| 碰 | 别人打出的牌,手里有 2 张即可碰;碰后直接出牌,不摸牌,这一回合不能胡也不能杠 |
| 直杠 | 别人打出的牌,手里有 3 张 |
| 暗杠 | 自己回合,手里有 4 张相同的牌 |
| 加杠 | 自己回合,已经碰过,手里有第 4 张。不要求立刻杠,之后任何一个自己的回合都可以 |
| 杠的限制 | 牌墙里至少还有 1 张牌才能杠(杠后要补牌) |
| 自摸 | 自己回合(摸牌后或杠后补牌后)成胡型 |
| 点炮 | 别人打出的牌让自己成胡型。可以选择不胡 |
| 响应优先级 | 胡 > 杠/碰 |
| 一炮多响 | 同一张牌多人能胡时全部成立,点炮者分别赔付 |
| 抢杠胡 | 别人加杠的那张牌可以胡,算点炮;杠不成立,没有杠分 |
| 最后一张 | 牌墙摸完后打出的最后一张弃牌只能胡,不能碰杠 |
| 血战到底 | 胡牌者离场,不再摸牌出牌,也不再为之后的胡牌和杠付分;其余玩家继续 |
| 胡牌后谁摸牌 | 胡牌者的下家(跳过已胡的人)。一炮多响时,从点炮者起数最远的那位胡牌者的下家 |

## 4. 胡牌与计分

**胡型**:4 组面子(顺子或刻子,含副露)+ 1 对将;或者七对(必须没有副露)。

**得分** = 底分 × 2^min(总番数, 封顶番数)

| 配置 | 默认 | 含义 |
|---|---|---|
| `base_score` | 1 | 底分 |
| `max_fan` | 5 | 封顶番数,即一次胡牌最多 32 倍底分 |
| `zimo_mode` | `"jia_di"` | 自摸加底:每家多付 1 个底分。可选 `"jia_fan"`(多算 1 番)或 `"none"` |

**谁付分**

| 胡法 | 付分者 |
|---|---|
| 自摸 | 所有还没胡的其他玩家,每人付一份 |
| 点炮、抢杠胡 | 点炮者(被抢杠者)一人付 |

### 4.1 牌型番

同一手牌有多种拆法时,取总番数最高的那种。

| 牌型 | 番 | 条件 |
|---|---|---|
| 平胡 | 0 | 普通胡型 |
| 对对胡 | 1 | 4 组面子全是刻子或杠 |
| 将对 | 3 | 对对胡,且所有牌都是 2、5、8(已含对对胡的 1 番) |
| 金钩钓 | +1 | 对对胡或将对,且 4 组面子全部副露,手里只剩单吊的将 |
| 带幺九 | 2 | 每组面子和将都带 1 或 9。可与对对胡叠加 |
| 七对 | 2 | 7 个对子 |
| 龙七对 | 3 | 七对里有 4 张相同的牌(即七对 + 一根) |

### 4.2 附加番

| 附加 | 番 | 条件 | 开关 |
|---|---|---|---|
| 清一色 | +2 | 所有牌同一花色 | — |
| 根 | 每根 +1 | 手牌加副露里有 4 张相同的牌(杠也算);龙七对已用掉的那一根不重复算 | — |
| 门清 | +1 | 没有碰、直杠、加杠(暗杠不破门清)。七对不另算 | `men_qing_zhong_zhang`,默认开 |
| 中张 | +1 | 所有牌都没有 1 和 9(即断幺九) | 同上 |
| 天胡 | +5 | 庄家起手 14 张直接胡 | `tian_di_hu`,默认开 |
| 地胡 | +5 | 闲家在自己第一次出牌之前胡牌,且此前全场无人碰杠 | 同上 |
| 杠上花 | +1 | 杠后补的牌自摸 | — |
| 杠上炮 | +1 | 别人杠后打出的牌点炮 | — |
| 抢杠胡 | +1 | 胡别人加杠的牌 | — |
| 海底捞月 | +1 | 摸到牌墙最后一张自摸 | `haidi`,默认开 |
| 海底炮 | +1 | 胡最后一张弃牌 | 同上 |
| 自摸 | +1 | 仅当 `zimo_mode = "jia_fan"` | — |

### 4.3 常见组合对照

组合牌型不单独列名,由上面的番数相加得到:

| 俗称 | 引擎给出的明细 | 番 |
|---|---|---|
| 清对 | 对对胡 + 清一色 | 3 |
| 清七对 | 七对 + 清一色 | 4 |
| 清龙七对 | 龙七对 + 清一色 | 5 |
| 清金钩钓 | 对对胡 + 金钩钓 + 清一色 | 4 |
| 十八罗汉(四杠单吊) | 对对胡 + 金钩钓 + 根×4 | 6(封顶 5) |

番值定义在 `chuanma/fan.py` 顶部的 `FAN_*` 常量里,要改番值改那里。

## 5. 杠分(刮风下雨)

杠成立时立刻结算,单位是底分。

| 杠 | 配置 | 默认 | 付分者 |
|---|---|---|---|
| 暗杠 | `an_gang_score` | 2 | 其余还没胡的玩家每人付 |
| 加杠 | `jia_gang_score` | 1 | 其余还没胡的玩家每人付 |
| 直杠 | `ming_gang_score` | 2 | 放杠者一人付 |

## 6. 流局结算

牌墙摸完时还有两人或以上没胡,对 **没胡的玩家** 做三项结算。三家胡牌结束的不做。

| 项 | 配置 | 规定 |
|---|---|---|
| 查花猪 | `cha_hua_zhu`,默认开 | 手里还有缺门牌的是花猪。每个花猪向每个不是花猪的未胡玩家赔封顶分(默认 32 倍底分) |
| 查大叫 | `cha_da_jiao`,默认开 | 没听牌的(不含花猪)向每个听牌的未胡玩家,赔对方 **可能胡到的最大番** 对应的分数(按点炮算,不含场况附加番) |
| 退税 | `tui_shui`,默认开 | 没听牌的玩家(含花猪)把本局收到的杠分原路退回 |

听牌的判断:再来一张牌就能胡,且那张牌自己还没占满 4 张。

## 7. 没有实现的规则

| 规则 | 说明 |
|---|---|
| 呼叫转移 | 杠上炮时把杠分转给胡牌者 |
| 过手胡(过水) | 放过一次点炮后,到自己下次摸牌前不能再胡同一张或更小的牌 |
| 报听、天听 | — |
| 血流成河 | 胡牌后继续留在牌局里反复胡的玩法 |
| 多局赛制 | 轮庄、连庄、累计积分由上层负责,引擎只管一局 |
| 掷骰子 | 换三张方向直接用随机数决定 |
| 南京麻将等其他规则 | 旧版的南京麻将骨架在 `legacy/`,新引擎不支持 |

## 8. 测试覆盖

上面每一条实现了的规则在 `tests/test_game_flow.py` 或 `tests/test_fan.py` 里都有对应的用例,用例名和注释写明了验证的是哪一条。
